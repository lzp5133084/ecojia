一、我们是谁

数字生态家园（ecojia.cn）由军哥懂保独立设计与开发，是一位专注保险与家庭保障领域的从业者， 出于「把复杂工具做简单、把零散服务做统一」的想法，逐步搭建起来的个人数字生活门户。

站点不追逐流量与广告收入，产品以免费为主，靠个人投入与用户反馈驱动迭代。目标是：让一个普通家庭， 用一套账号、一套界面，就能把证件保管、计时专注、资料查找、屏幕标注这些日常小事一次配齐。

二、我们提供什么

  • 统一账号体系：一次注册，生态内产品共用身份，不用反复填资料。
  • 主打产品：数字保险箱（家庭重要资料加密保管）、悬浮计时器（三端同步专注工具）、 鼠标画笔（教学直播办公标注神器）、资料百事通（全民共创资料库）、多码集（聚合码管理）。
  • 工具清单：35 款自研工具的使用说明、运行方式与下载入口，按编号速查。
  • 许愿墙：把您想要的功能写下来，需求集中度高的会优先开发。
  • 火星平面：给每个人一张火星身份证，记录人生七类历程并做完整性存证。
  • 开放接口：站点作为生态底座，公开接口清单（/api/ecosystem/manifest），方便其他程序调用。

三、技术架构

层级方案
网关 / 反向代理Caddy 2（自动 HTTPS、HTTP/3、gzip / zstd 压缩、统一安全响应头）
应用服务Flask + gunicorn（gthread 多线程 worker），systemd 托管，仅监听 127.0.0.1
数据存储SQLite（本地文件），定时备份
前端原生 HTML / CSS / JavaScript，无框架依赖；图片提供 WebP 与 JPEG 双格式回退
AI 能力火山方舟（豆包）大模型接口
部署环境腾讯云 · Ubuntu · 中国境内节点

全站不引入第三方统计与广告脚本，页面首屏以「少请求、小体积」为设计前提。
