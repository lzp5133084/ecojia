1
先填目标和期限
目标金额填你想拿到的净额（不是营业额）。期限可以切年 / 月 / 日，天数会自动折算。
2
看倒推结果
右侧七张卡从「每年」一路细到「每秒」。重点看每秒需赚，它是计时器的计算基准。
3
按下开始，看钱流走
计时器按真实时间累计损失金额，精确到分。中途可暂停、可继续、可重置。改参数会自动重置。
4
保存与回看
点「保存记录」存一份快照，之后可一键载入、加备注、单独删除。数据只在本机。
5
AI 建议怎么用
填写最多若干个职业、每天投入时长和月收入。接口未配置时只展示说明，不编造结果；配置后端代理后才会真正分析。
6
被别的程序调用
页面暴露了全局对象 window.MoneyPower，可以读取核算结果、触发分析、导入导出数据。
倒推核算先定结果，再倒着算过程。比如「3 年要 100 万」，倒推就是每年 33.3 万、每天 913 元。
时薪（工作时段）只算你真正干活的小时数，不含摸鱼和休息。它比「自然小时」更能反映你的劳动单价。
自然小时按一天 24 小时算的平均值。睡觉也在「流失」，所以数字明显更小。
千分位数字每三位加一个逗号，例如 1,000,000，方便一眼读出量级。
期限进度已经过去的时间占整个目标期限的百分比。哪怕只过去一分钟，它也不是 0。
流失金额每秒应得 × 已过秒数。它衡量的是「这段时间按目标折算值多少钱」，不代表你实际亏了现金。
// 1. 核算：不改动页面，只拿结果
MoneyPower.calculate({
  target: 1000000,
  deadlineValue: 1,
  deadlineUnit: 'year',   // year | month | day
  workHoursPerDay: 8
});
// → { days, perYear, perMonth, perDay, perWorkHour, perHour, perMinute, perSecond }

// 2. 读取当前页面状态
MoneyPower.getSnapshot();

// 3. 触发 AI 分析（需先配置代理接口）
MoneyPower.analyze({ careers: [...] })
  .then(r => r.ok ? r.data : r.message);

// 4. 配置接口 / 数据导出导入
MoneyPower.setAiEndpoint('https://your-domain.com/api/money-power');
MoneyPower.exportJSON();          // 返回全部历史记录 JSON 字符串
MoneyPower.importJSON(jsonStr);   // 合并导入

// 5. 监听每秒心跳
MoneyPower.on('tick', s => console.log(s.elapsed, s.lost));
诚实边界本工具只做目标倒推与时间成本换算，不预测收入、不承诺任何结果。所有数字来自你自己填的目标与期限，属于算术推演，不构成投资、职业或财务建议。
流失金额的含义它是「这段时间按目标折算值多少钱」，不等于你实际亏了现金，也不代表你一定赚得到。
折算口径1 年按 365 天算，1 月按 30.4167 天算（365 ÷ 12），不考虑闰年、节假日和工作日日历。
计时机制基于本机系统时间累计；刷新或关闭页面后计时从头开始，不做后台续算，也不跨设备同步。
数据与隐私纯本地运行，不联网、不上传、页面内不含任何密钥。历史记录只存在本机浏览器，清理浏览器数据会丢失。
AI 建议需要你自建后端代理接口。接口未配置或返回格式不符时，页面只给说明，不会编造结论，也不会偷偷联网。
动画降级系统开启「减少动态效果」或设备核心数较低时，自动关闭翻牌、流光与脉冲，改为纯文本刷新。
