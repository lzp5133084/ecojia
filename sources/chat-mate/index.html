现实里缺人的时候，按你要的属性拼一个「模板角色」，陪你把聊天框架先搭起来。它是设定卡，不是真人。

诚实边界：没有接入大模型接口时，补位角色只是一张「角色设定卡」——它不会自己回话，也不会在线等你。点「开始聊天」若接口未配置，只会弹提示，不会编造任何回复。

所有数据存在这台设备的浏览器 localStorage 里，换设备/清缓存会丢，建议定期导出备份。

隐私：真人资料只存本机，不上传、不联网、不请求任何外部地址。导出的 JSON 请自己保管好。

直接从 Excel / 飞书表格复制一整块粘进来，或者粘 CSV 文本。系统会自动认列，认错了可以手动改。

    1
    先填你自己的资料

    点「编辑我的资料」，填出生年月日（或直接选星座 + 生肖）。这是算契合度的基准。

    2
    把人加进来

    手动新增，或从表格整块粘进来批量导入。真人、AI 扮演、模板补位角色可以混着放，你自己贴标签。

    3
    看排序，点开看怎么说

    列表默认按契合度从高到低。点「看怎么聊」会给你聊天节奏、3 个话题、第一句示例、要避开的话题。

    契合度

    一个 0–100 的分。越高代表按生肖和星座的固定规则，你们越容易聊得顺。它只是参考，不是判决书。

    六合 / 三合

    生肖里最合得来的组合。六合是一对一最搭，三合是三个生肖抱团最搭。这两类给分最高。

    六冲 / 六害 / 相刑

    生肖里容易别扭的组合。冲是正面顶牛，害是暗里别扭，刑是互相磨。分数会低，但不是不能聊，只是要更注意分寸。

    四元素

    星座分火、土、风、水。火配风、土配水比较顺；火配水、土配风容易互相看不懂。

    相位（三分 / 六分 / 四分 / 对宫）

    两个星座在星盘上的角度关系。三分（120°）、六分（60°）是顺的；四分（90°）是拧巴的；对宫（180°）是互补但容易互相拉扯。

    补位

    缺人的时候，按你想要的属性拼一个虚构角色出来，帮你先把聊天场景搭起来。它不是真人。

    模板生成

    从内置的昵称、语气、雷区库里按固定规则拼出来，同样条件永远得到同一个角色。不是大模型现编。

    VIP 角标

    你自己给候选人打的标记，纯装饰，方便把重点人选顶出来，不影响评分。

    1. 生肖按出生年份简化计算（未按立春精确换年），星座按公历日期计算，边界日可能有 1 天误差。

    2. 评分是固定规则表的加减法，不含任何随机数，同样两个人算两次结果完全一致。

    3. 补位角色是「角色设定卡」，不接大模型就不会说话。页面不会假装它在线。

    4. 真人资料只在你本机，不上传。清缓存或换浏览器会丢，记得导出备份。
